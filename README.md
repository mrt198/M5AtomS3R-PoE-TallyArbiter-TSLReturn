Tally Arbiter M5Stack Atom S3R listener with support for the AtomPoE unit.  Displays Status on screen, along with an NTP clock to help your presenter!

Usage: Click button to set Program on return TSL channel (TP Mode).  Double click to show status page.  Configuration via web interface at port 80.
